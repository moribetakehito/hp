# works の更新方法

## いちばん簡単な方法

1. `https://moribetakehito.com/admin/` を開く
2. GitHubでログインする
3. `Site Data` → `Works` を開く
4. 作品情報を追加・編集する
5. `Images` に画像をアップロードする
6. 保存する

保存すると `works/data.json` と画像ファイルがGitHubに反映され、`/works/` の一覧にも出ます。

## 表示順について

`Works` のリストは、上にある作品ほど `/works/` の上に表示されます。

新しく追加した作品は自動で一番上に入るので、基本的には新しい作品が上、古い作品が下になります。

古い作品をあとから編集しても、表示順は勝手には変わりません。順番を変えたいときだけ、管理画面の `Works` リスト内で作品を並び替えて保存します。

## 説明文のリンクについて

`Description` の文中リンクは、次の形で書けます。

```text
詳しくは[こちら](https://example.com)を見てください。
```

サイトでは「こちら」だけがリンクになります。

## 新しい作品について

新しい作品は、作品IDを使って `/works/作品ID/` で表示されます。

例:

```text
/works/20260601_new_work/
```

`ID` は半角英数字・ハイフン・アンダーバーで付けると扱いやすいです。IDを変えると作品URLも変わるので、公開後はなるべく変えないでください。

## 画像について

管理画面からアップロードした画像は `works/uploads/` に入ります。表示順は `Images` の並び順です。

## 既存ページについて

既存の `/works/20260511_cp/` はそのまま残しています。内容は `works/data.json` から読み込まれます。
